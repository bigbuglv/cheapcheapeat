02

03

Generate & download

Each suburb gets its own SEO-optimised HTML page: cheap-eats-footscray.html, cheap-eats-cabramatta.html, etc. Push them all to your GitHub repo root. Google will index each one as a separate page targeting that suburb's search queries.

Each page includes: full restaurant listings, price tiers, addresses, cuisine types, a back link to the main site, and LocalBusiness + ItemList schema markup so Google can show rich results.
